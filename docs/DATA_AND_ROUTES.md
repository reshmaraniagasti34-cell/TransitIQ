## 2. Dataset Structure (`server/data/historicalTrips.json`)
The historical dataset contains **50 total trips** comprising **245 historical segment records**.

### Attribution Breakdown
- **1 Observed Pilot Trip (`TRIP-101`)**: Field timing data logged directly on the pilot corridor.
- **49 Physics-Constrained Simulated Trips (`TRIP-SIM-001` to `TRIP-SIM-049`)**: Generated by sampling segment travel speeds with $\pm 15\%$ Gaussian variation around observed baseline corridor speeds.

### Record Schema
Each trip entry in `historicalTrips.json` follows this structure:
```json
{
  "trip_id": "TRIP-101",
  "direction": "SEHORE_TO_VIT",
  "day_of_week": "weekday",
  "time_of_day_bucket": "morning",
  "segments": [
    {
      "from_stop": "Sehore Bus Stand",
      "to_stop": "Kubreshwar Dham",
      "distance_km": 10.5,
      "start_time": "2026-03-01T08:00:00Z",
      "end_time": "2026-03-01T08:18:00Z",
      "duration_minutes": 18.0
    }
  ]
}
```

---

## 3. Data Field Meanings
- **`latitude` / `longitude`**: Decimal degree WGS84 geographic coordinates representing current vehicle position.
- **`accuracy`**: Radius of position uncertainty in meters (provided by mobile GPS hardware).
- **`timestamp`**: ISO-8601 string of when the location measurement was captured.
- **`duration_minutes`**: Elapsed travel time recorded between two consecutive corridor waypoints.

---

## 4. Controlled Scope & Limitations
- **Single Corridor Scope**: TransitIQ is verified exclusively on the Sehore $\leftrightarrow$ VIT Bhopal pilot corridor.
- **Data Authenticity**: All simulated trips are explicitly labeled (`TRIP-SIM-xxx`) and are never misrepresented as field-observed data.
- **Excluded Places**: Unverified locations (such as Bairagarh, Crescent Water Park, Phanda Toll Plaza, Bhopal ISBT) and fabricated fleets (Bus 101/102/103) are omitted from active views.
